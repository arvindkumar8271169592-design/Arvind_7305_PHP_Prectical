PRACTICAL 3.10 - PHP REGISTRATION FORM

Files:
1. registration.php - Registration form and database insertion
2. database.sql - Database and users table SQL

HOW TO RUN:
1. Start Apache and MySQL in XAMPP.
2. Open http://localhost/phpmyadmin
3. Import/run database.sql.
4. Copy the Practical_3_10_PHP_Registration folder into C:\xampp\htdocs\
5. Open:
   http://localhost/Practical_3_10_PHP_Registration/registration.php

Database:
Database name: practical_db
Table name: users
